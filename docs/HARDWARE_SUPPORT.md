# Hardware support

Target architecture: x86_64. Initial target is a VM; no physical machine has been
validated. BIOS and UEFI validation is pending.
Crazyradio/Crazyradio PA/Crazyradio 2.0 compatibility must be recorded against the
exact USB identifiers, firmware and cflib version tested. No model is certified yet.
Crazyradio communicates with supported Bitcraze devices; it is not a universal
spectrum analyzer. SDR is a separate future module.

Crazyflie, ESP32, ESP32-C3, Arduino and MAVLink tooling remain planned. Record board,
firmware, adapter, permissions, test commands and results before claiming support.
Do not install broad USB access rules or promise telemetry without hardware tests.
