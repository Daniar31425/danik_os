# Roadmap

1. Foundation: documentation, baseline overlay, build/check tooling. ISO build and
   VM acceptance pending.
2. Desktop: Plasma, NetworkManager, ordinary user and explicit administration,
   firewall and minimal services. Accept a verified desktop ISO.
3. Network Lab: real diagnostics, connection inspection and exports.
4. Crazyradio: cflib, permissions, real telemetry and disconnect recovery; execute
   RF-01 through RF-10 on documented hardware.
5. IoT and Developer: installable optional profiles and focused integration tests.
6. Interface: asynchronous QML dashboard, observed network map, RF and commands.
7. Release: VM/hardware tests, update/recovery checks and reproducibility work.

Each step requires recorded acceptance before the next is considered complete.
